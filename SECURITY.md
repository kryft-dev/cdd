# Security Policy

## Supported Versions

Only the latest release of cdd is supported with security fixes.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting, available on this repository's **Security** tab
(**Security** -> **Advisories** -> **Report a vulnerability**). Do not open a
public issue for a security vulnerability.

We will acknowledge your report and work with you to understand and address
the issue.
